Guessing Game (Streamlit App)

A simple interactive number guessing game built with Python and Streamlit.

The app randomly selects a number between 1 and 100, and the player has 7 attempts to guess it correctly.

The application:

Randomly generates a number between 1 and 100

Allows the user 7 attempts to guess the correct number

Provides instant feedback:

Too High

Too Low

Correct 

Displays remaining guesses

Allows the user to restart the game
